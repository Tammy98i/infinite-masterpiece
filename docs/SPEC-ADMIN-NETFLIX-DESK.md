# CRM Netflix desk — אפיון סקיצה

איור ראשוני לפני ביצוע. **אין שינוי קוד ב־`src/` עד «קדימה».**

לוח אינטראקטיבי: [`crm-netflix/sketch.html`](crm-netflix/sketch.html)

## מטרה

להתאים את דסק ה־CRM לשפת **ספריית נטפליקס האקדמית** (שמיים + ווילים + כרום 4px), בלי למחוק טאבים או פעולות קיימות.

## חמש שכבות

| # | שכבה | היום | בסקיצה / אחרי «קדימה» |

| 01 | חושך מעל התמונה | library + CRM veils כפולים; כרטיסים אטומים | ווילי CRM ייעודיים f–h; כיבוי library veils תחת `.crm-desk`; כוכבים נראים |
| 02 | כרום נטפליקס | `glass` / `#0a0a0a` / `rounded-3xl` | `.crm-desk-panel` navy שקוף, רדיוס 4px — כמו פסי ספרייה |
| 03 | סקירה | כרזה + 4 מדדים (מינימלי) | אותה כרזה; מדדים בסגנון plan-strip / שפת קטלוג |

## חוזה ווילים (אחרי «קדימה»)

1. `SkyBackdrop` ממשיך לשרת את כל האתר.
2. תחת `.crm-desk` (או מחלקה מקבילה):
   - **כיבוי** ווילי library כפולים שלא נועדו לדסק.
   - **הפעלת** ווילי CRM חדשים:
     - `f` — גרדיאנט תחתון לקריאות טבלאות
     - `g` — צל צד לסיידבר
     - `h` — רדיאלי מרכזי רך
3. `main` של הדסק מקבל stage veil קל (כמו סקיצת `main::before`).
4. הספרייה הציבורית (`/library`) **לא משתנה**.

## כלל הזהב

כל מה שנשאר — נשאר. מה שמשתנה הוא **חושך, שקיפות, ושפת כרום**. 23 הטאבים בסיידבר.

## גבולות מוצר

- ספרייה ≠ מסע / 88. לא לערבב CTA.
- הססנים 8→80→800→8,000 (מחיר מלא, לא הנחה).
- מייסד = `is_founder`. קפטן = `pod_role`.
- בלי תגובות על תכנים, AI, אפליקציה, גיימיפיקציה (שלב 2).

## מיגרציה עתידית (רק אחרי «קדימה»)

1. `SkyBackdrop` — ווילים f–h + הסתרת library veils תחת `.crm-desk` + stage veil ב־`main`.
2. `.crm-desk-panel` / `.crm-desk-table` / metric strip ב־[`CrmDesk.css`](../src/styles/CrmDesk.css).
3. מיגרציית class בפאנלים אטומים בלי שינוי לוגיקה.
4. מונוגרם בשורות + כרטיס דק; AsideVeils למרצה במקום רקע אטום.
5. בדיקה ויזואלית מול `/library`.
