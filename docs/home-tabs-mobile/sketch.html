סרגל נושאים במובייל — נבחר במרכז + הצצה

סקיצה ל־TabbedSlider בעמוד הבית: בגרסת מובייל הטאב הנבחר תופס את הבמה, והשכנים מציצים מהצד כדי לרמוז שיש עוד עמודים ללחיצה.

מה הבנתי

  1. הסרגל: שורת הטאבים הדביקה של עמוד הבית (במה זה שונה / תהליך / צוות / פלטפורמה / מחירון / שאלות) — לא תפריט המבורגר ולא ספיין הוובינר.
  2. היום במובייל: כל הטאבים בשורה גלילה צפופה; הנבחר מסומן בקו זהב, אבל לא «בעיקר» — קשה לראות שיש עוד.
  3. הרצון: הנבחר מופיע בעיקר במרכז; מהצד מציצים טאבים שכנים (חצי / מעומעמים) כרמז שיש עוד עמודים.
  4. אינטראקציה: לחיצה על טאב מציץ → מעבר מיידי לאותו פאנל (כמו היום: החלפת תוכן + hash).
  5. מחוץ לסקופ לסקיצה: דסקטופ נשאר מיושר־מרכז מלא; אין שינוי בתוכן הפאנלים עצמם.

נבחר במרכז — גדול, זהב מלא, קו תחתון. הצצה לשכנים — מעומעמים / חתוכים בקצוות. לחיצה — השכן הופך לנבחר והסרגל «מזין» אותו למרכז.

התנהגות מוצעת (ליישום בהמשך)

ב־≤900px: הסרגל מציג שלושה «חריצים» — prev · active · next. הטאב הפעיל תמיד בחריץ המרכזי; לחיצה על prev/next מזיזה את המדד ומעדכנת את הפאנל (אותו selectTab + hash כמו היום). Edge-fade מסמן שיש עוד מעבר לקצוות הרשימה. דסקטופ: ללא שינוי — כל הטאבים בשורה ממורכזת.
