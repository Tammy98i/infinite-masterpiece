## ההצעה הפרקטית

שלושה דברים על אותו דסק (`/library/admin` סקירה), בלי לקפוץ בין 23 טאבים לטיפול יומיומי:

| | מה | למה |
| --- | --- | --- |
| **מדגיש** | פס «לטיפול עכשיו» עם שם אדם + פועל | היום «מעבר לטיפול» בלי יעד |
| **מחבר** | בחירת יוזר פותחת כרטיס מחובר: מנוי · מסלול · ליד · פוד · 88 | אותם נתונים מפוזרים בטאבים נפרדים |
| **משפר** | טבלה צפופה, חיפוש לפי שם, עריכה והסרה בשורה | שורות גבוהות, טופס פתוח, אין הסרה |

כל הטאבים נשארים בסיידבר לעבודה עמוקה. העמוד האחד הוא נקודת הכניסה.

הספרייה הציבורית נשארת עמוד אחד משלה: כרזה + פסים אקדמיים, שכבות כהות, בלי לערבב CTA מסע.

## אבחון מהקיים

- חיפוש שם+אימייל כבר קיים. עריכה בכרטיס צד. **אין הסרה** — רק חסימה.
- טופס יצירה תמיד פתוח. `משתמשים` ו־`גישה` מציגים אותה רשימה.
- ליד, פעימת הססנים, מועמדות 88 ופוד יושבים במסכים נפרדים לאותו אדם.

קוד במוצר, תגובות, שאלות למרצה, AI, אפליקציה, גיימיפיקציה, Revenue Share, CTA ספרייה על דף המסע.
