# סקיצת אדמין + ספרייה אקדמית

איור לפני ביצוע. לא קוד במוצר. לא מוחקים אף מסך או פעולה קיימים.

לוח אינטראקטיבי: [`admin-library/sketch.html`](admin-library/sketch.html)

## מה רואים בלוח

| מסך | מה מוצג |
| --- | --- |
| מפה | כל עמודי `/library/admin`: מה לא ברור, מה נשאר |
| יוזרים | טבלה צפופה, חיפוש לפי שם, עריכה והסרה בשורה |
| אדמין | פעולות פרקטיות בכל קבוצה — תווית ברורה, בלי לגרוע |
| ספרייה | הירו + פסים כמו נטפליקס, לקורסים ולטכנאים אקדמיים |
| שכבות | שכבות כהות נוספות מעל תמונת החלל |
| נשאר | מה לא מוחקים ומה לא נכנס לשלב 2 |

## אבחון קצר מהקיים

- חיפוש משתמשים לפי שם+אימייל כבר קיים. עריכה חיה בכרטיס צד אחרי לחיצה על שורה. **אין הסרה** — רק חסימה.
- טופס «הוספת משתמש» תמיד פתוח. שורות גבוהות (שם + אימייל + צוות). הטבלה תופסת חצי מסך + כרטיס.
- `משתמשים` ו־`משתמשים · תפקידים · הרשאות` מציגים אותה רשימה בשני מקומות.
- כפתורי זהב עגולים («מעבר לטיפול») בלי יעד מפורש. פעולות נסתרות עד שבוחרים שורה.

## כיוון אחרי אישור

1. שורות צפופות בשורה אחת. יצירה מאחורי כפתור. חיפוש דביק לפי שם.
2. `עריכה` ו־`הסרה` בשורה. הסרה = מחיקת חשבון עם אישור. חסימה נשארת פעולה נפרדת.
3. כל טאב בסיידבר נשאר. רק התוויות והצפיפות משתנות.
4. ספרייה: עוד שכבות כהות, הירו כרזה, פסים אקדמיים, Play לבן / עוד אפור. בלי להסיר טעימה, Paywall, המשך צפייה, מרצים, נושאים.
5. לא מערבבים CTA מסע עם מנוי ספרייה.

## מה לא בסקיצה

קוד במוצר, תגובות על תכנים, שאלות למרצה, AI, אפליקציה, גיימיפיקציה, Revenue Share, CTA ספרייה על דף המסע.
