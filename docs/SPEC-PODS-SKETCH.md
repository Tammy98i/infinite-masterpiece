# סקיצת Pods

איור לפני ביצוע. לא קוד במוצר. Pods שייכים למסע, לא לספרייה. באפיון הראשי זה שלב 2.

האפיון המלא: [`SPEC-PODS.md`](./SPEC-PODS.md).

לוח אינטראקטיבי: [`pods/sketch.html`](pods/sketch.html)

## מה רואים בלוח

| מסך | מה מוצג |
| --- | --- |
| מפה | פוד = קבוצה קטנה. קפטן: ביצוע, שאלות, קצב |
| תלמיד | הפוד שלי: קפטן, קבוצה, משימת השבוע, פגישה הבאה |
| קפטן | רק הפוד שלו. מי הגיש, מי תקוע, תזכורת, חדר |
| אדמין | תור שיוך אחרי תשלום מסע. מנוי ספרייה לא נכנס |
| נבחרת 88 | Micro-Pod נפרד. לא אותו CTA |
| לא כאן | תגובות, AI, צ׳אט, אפליקציה, הבטחת הכנסה, בנייה עכשיו |

## גבולות מהאפיון

- ספרייה = מנוי צפייה. מסע / 88 = מועמדות וליווי. לא לערבב באותו כפתור.
- מודל הנתונים הנוכחי ב־`SPEC-VOD-PLATFORM.md` לא כולל `pods`.
- שלב 2: Community · Pods · שאלות למרצה · AI · אפליקציה.

## מה לא בסקיצה

קוד במוצר, תשלום לקפטן, Revenue Share, פיד קהילה, תגובות על הרצאות.
