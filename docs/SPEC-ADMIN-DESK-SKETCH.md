# סקיצת דשבורדים — עמוד־עמוד

איור לפני ביצוע. לא קוד במוצר. לא מוחקים אף טאב או פעולה.

הצפיפות כבר במוצר (`/library/admin`). הסקיצה הזו מציירת **חיבור ובהירות** ב־23 הטאבים שנשארו שבורים או כפולים.

לוח אינטראקטיבי: [`admin-desk/sketch.html`](admin-desk/sketch.html)

## גבולות מוצר

- ספרייה = מנוי צפייה. מסע / 88 = מועמדות וליווי. לא לערבב באותו CTA.
- הססנים מחיר מלא: 8 → 80 → 800 → 8,000. לא הנחה.
- מייסד = `is_founder`, לא role. קפטן = `pod_role`.
- הצפיפות שכבר במוצר (עריכה / הסרה / חיפוש שם) לא חוזרת לכאן.

## מה לא בסקיצה

קוד במוצר, תגובות, שאלות למרצה, AI, אפליקציה, גיימיפיקציה, Revenue Share, CTA ספרייה על דף המסע.
בנייה רק אחרי «קדימה».
